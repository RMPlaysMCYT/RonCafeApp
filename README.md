_____
## Features
* Add Game Selection
* Add Categories
* Add Game Cover Art

## Upcoming Features
* Coin Timer for Business Edition 

### Framework used
- AvaloniaUI
- SQLite

### For Developers
_____
In order to continue and try to customize it
1. Install .Net 9.0 on Windows and Linux
2. Install Avalonia Templates
   If It can't be found or error
   2.1. Check it via typing ```dotnet nuget list source```
   If There's no one Well type this ```dotnet nuget add source https://api.nuget.org/v3/index.json -n nuget.org```
3. Once Added and try to type this on Command Prompt or Terminal ```dotnet new install Avalonia.Templates```
4. Type ```cd roncafeapp```
5. Once you press enter and type this ```dotnet restore``` and wait till everything is restored
6. Open your preferred IDE Wether Visual Studio(Windows) or Rider(Windows/Linux/Mac) and work on your own
